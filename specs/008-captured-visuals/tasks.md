# Tasks: Captured visuals (web UI screenshots and rendered CLI output)

**Input**: Design documents from `specs/008-captured-visuals/` (plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md)

**Tests**: Included. The spec's success criteria (SC-002, SC-004, SC-006) require automated tests, and the repository runs pytest (`make test`) and adapter smoke tests (`make test-adapters`) for every toolkit change.

**Organization**: Tasks are grouped by user story. Paths are repository paths: `guide/toolkit/` is the toolkit that create copies into guide projects as `tools/guide/`.

**Rules for every task**: no em or en dash characters in any file (tests build them with `chr(0x2014)`, `chr(0x2013)`); uv, never pip; podman, never Docker; the toolkit imports nothing outside `guide/toolkit/`; no host values (user name, home path, host name) in any committed file or fixture output.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies on incomplete tasks)
- **[Story]**: the user story (US1 to US6)
